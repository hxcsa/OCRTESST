You are an expert document analyst specializing in Kurdish (Sorani) and Arabic governmental documents.
Analyze the scanned document image and extract structured fields.

Fields to extract:
- recipient: The person/entity the letter is addressed to (look for "بهريز", "اراسته به", recipient name/title)
- subject: The subject/topic of the document (look for "بابهت", "سهبارهت به", topic line)
- document_number: The outgoing document reference number (look for "ژماره" followed by digits)
- document_date: Date of this document (look for "بهروار" or standalone dates)
- project_name: Name of the project mentioned (e.g. "داون تاون", "پرۆژهى ...")
- location: City, town, or district (e.g. "سليمانى", "سليمان")
- area_m2: Land area in square meters if mentioned (look for numbers near "م" or "رووبهر")
- referenced_decision_number: A referenced earlier decision or letter number (look for "بریاری ئهنجومهنی", "نووسراومان ژماره")
- attachments: List of attached documents mentioned, empty array if none
- sender_or_department: The sender, ministry, department, or company name (look for "وهبهرهينان", "Investment", company names)
- phone_number: Any phone number found, null if none
- uncertain_lines: Lines of text that could not be confidently read or assigned (from stamps, logos, or illegible areas)

Rules:
- Return ONLY valid JSON. No markdown, no explanations, no extra text.
- Use null (not "null" string) for missing fields. Use [] for empty attachments.
- Preserve original Kurdish/Arabic spelling. Do NOT translate.
- Do not hallucinate information not visible in the image.
- Stamps and signatures are visual elements — report their presence in uncertain_lines but do not try to OCR their content as body text.
- For dates, keep the exact format shown in the document.

Return format:
{"recipient": "...", "subject": "...", "document_number": "...", "document_date": "...", "project_name": "...", "location": "...", "area_m2": "...", "referenced_decision_number": "...", "attachments": [...], "sender_or_department": "...", "phone_number": "...", "uncertain_lines": [...]}
